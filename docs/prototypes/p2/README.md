# P2. Proxies without originals

Question from section 12 of the plan: on a workstation that only has the `Proxy` folders, are clips linked to their proxies, and can you edit?

This is the normal case for a Banc workstation: originals stay on the depot and on the workstation that did the ingest, the others fetch the proxies (section 5 of the plan). If the answer is no, file sharing has to be rethought.

You need one workstation with Resolve Studio, ideally two (Mac and PC) for scenario B. The Banc volume from P1 helps but is not required: any folder will do for scenario A. Allow two to three hours.

The scripts are in `docs/prototypes/scripts/`. Read its `README.md` first. The commands below are run from that folder.

## 1. Preparing the rushes and their proxies

Real rushes from the team are better than test files, especially if they are BRAW or R3D. Proxies must end up in a `Proxy` subfolder next to the originals, with the same file name:

```
/Volumes/Banc/P2/Rushes/D01/CamA/A001.braw
/Volumes/Banc/P2/Rushes/D01/CamA/Proxy/A001.mov
```

Three ways to get them, from closest to the future Banc to simplest. Do at least one and record which:

1. **Proxies generated by Resolve.** In the project settings, set the proxy generation location so that they go into a subfolder next to the originals (record the exact name of the setting and its value). Import the originals, right-click > Generate Proxy Media.
2. **Blackmagic Proxy Generator**, watching the `Rushes` folder. Record whether it puts the proxies in the same place.
3. **Test files**, if nothing else is available:

   ```bash
   python3 test_media.py /Volumes/Banc/P2/Rushes/D01/CamA --count 3
   ```

   UHD originals in ProRes 422 HQ, 960x540 proxies in ProRes Proxy, same timecode.

In Resolve, create the `P2` project and import the originals (not the proxies). Edit a timeline with the three clips: a cut, a reframed clip, a transition.

```bash
python3 inventory.py --output ../p2/0-full.json
```

Record:

- [ ] With options 2 and 3, did Resolve link the proxies by itself on import? In `0-full.json`, the `Proxy Media Path` field of each clip must be filled in.
- [ ] The names of the proxy fields returned by the API (`Proxy`, `Proxy Media Path`, others?).

If the proxies are not linked, go to section 4 before continuing.

## 2. Scenario A: same workstation, originals removed

1. Quit Resolve.
2. Move the originals out of the volume, without touching the `Proxy` folder:

   ```bash
   mkdir -p ~/P2-removed-originals
   ```

   ```bash
   mv /Volumes/Banc/P2/Rushes/D01/CamA/A00* ~/P2-removed-originals/
   ```

3. Open Resolve and the `P2` project.

   ```bash
   python3 inventory.py --output ../p2/A-no-originals.json
   ```

Observe, for each of the three settings in the Playback > Proxy Handling menu (record the exact names):

- [ ] Do the Media Pool clips appear offline, or with their proxy? Which icon or badge?
- [ ] Do the viewer and the timeline play?
- [ ] Can you edit: put a clip in the timeline, cut it, trim it, change a reframe?
- [ ] Does the Color page work on the proxy? Any warning message?
- [ ] Does the timeline reframe (made on the UHD original) stay correct on the 960x540 proxy? This is the question of proxy resolution versus timeline resolution.
- [ ] Rendering from the Deliver page without the originals: refused, done on the proxies, or done with a warning? Record the render setting involved ("Use proxy media" or equivalent).

Then put the originals back in place, with Resolve closed, and reopen the project:

- [ ] Does Resolve switch back to the originals by itself, without relinking by hand?

## 3. Scenario B: another workstation, proxies only

The real case. P1 must have answered for the Mapped Mount if the two workstations do not run the same OS.

1. On the first workstation, export `P2.drp`.
2. On the second workstation, recreate only the `Proxy` folders at the same path (`/Volumes/Banc/P2/...` or `B:\P2\...`), without any original.
3. Import `P2.drp`, open the project.

   ```bash
   python3 inventory.py --output ../p2/B-other-workstation.json
   ```

Same observations as scenario A, plus:

- [ ] Are the proxies found even though they never existed at this path on this workstation?
- [ ] Add a clip to the timeline on this workstation, export the `.drp`, reopen it on the first workstation, which has the originals: does the edit made on proxies apply correctly to the originals?

## 4. Fallback: linking through the API

To do if Resolve did not link the proxies by itself, on import or in one of the scenarios. First the list, without changing anything:

```bash
python3 link_proxies.py
```

Then the link:

```bash
python3 link_proxies.py --apply --output ../p2/links.json
```

Record:

- [ ] Does `LinkProxyMedia` accept the link when the original is offline (`link_accepted`)?
- [ ] Does the link survive closing and reopening the project?
- [ ] In scenario B between Mac and PC: is the `original` field in the other OS's format? In that case the script does not find the `Proxy` folder, and that is information for P5.
